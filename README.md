# Compass Coordinates

Плагин для Paper/Spigot: показывает координаты только когда в руке компас. Координаты выводятся в action bar и в окне F3. Для F3 используется «фейковый» `reduceDebugInfo`, переключаемый пакетами через ProtocolLib. Если компаса в руке нет — координаты скрываются везде (включая F3) тем же способом.

## Возможности
- Показ координат в action bar при удержании компаса.
- Показ/скрытие координат в F3 через "фейковую" отправку reduceDebugInfo на клиенты).
- Кастомизация формата и интервала обновления action bar.

## Требования
- JDK 17\+ (рекомендуется LTS, совместимо с современными сборками Paper/Spigot).
- Сервер Paper/Spigot соответствующей версии Minecraft.
- Плагин ProtocolLib на сервере.
- (Опционально для сборки) Maven или Gradle.

## Установка
1. Собрать \*.jar (см. раздел «Сборка») или скачать готовый релиз.
2. Поместить \`.jar\` в папку \`plugins\` вашего сервера.
3. Убедиться, что ProtocolLib установлен и совместим по версии.
4. Перезапустить сервер или выполнить \`/reload\` (не рекомендуется на продакшене).
5. При необходимости отредактировать \`plugins/CompassCoordinates/config.yml\` и перезапустить сервер.

## Конфигурация
Файл \`plugins/CompassCoordinates/config.yml\` (пример):
```yaml
# Включать ли плагин
enabled: true
# Раз в сколько тиков обновлять action bar (20 тиков = 1 секунда)
delay: 5
# Текст для action bar (плейсхолдеры ниже)
text: "§6%dir§r | §6X:§r %x §6Y:§r %y §6Z:§r %z"
# Какой текст выводить для направления (используется в плейсхолдере %dir%)
directions:
  north: "N"
  northeast: "NE"
  east: "E"
  southeast: "SE"
  south: "S"
  southwest: "SW"
  west: "W"
  northwest: "NW"
```
Поддерживаемые плейсхолдеры:
- `%x`, `%y`, `%z` — координаты игрока.
- `%dx`, `%dy`, `%dz` — координаты игрока с точностью до десятых.
- `%world` — имя мира.
- `%yaw`, `%pitch` — ориентация игрока.
- `%dyaw`, `%dpitch` — ориентация игрока с точностью до десятых.<br>
- `%dir` — направление (N, NE, E, SE, S, SW, W, NW) в зависимости от ориентации игрока.
- Цвета в формате `&`-кодов (§-коды будут сконвертированы).

## Совместимость и поведение
- Координаты показываются только при удержании компаса в любой активной руке.
- При отсутствии компаса плагин отключает показ координат в F3 (через ProtocolLib) и в action bar.
